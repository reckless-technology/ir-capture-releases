# Reckless IR Capture

The downloads of Reckless IR Capture: it measures the impulse response of your own speaker cabinet - an audio
interface's output into a power amplifier, the cabinet, and a microphone in front of it back into the interface's
input - and exports it as a WAV file for the Reckless Cab or any other IR loader. Free for any use, for macOS, Windows
and Linux, with a command-line tool beside the app.

| | | |
|---|---|---|
| macOS 13.3 (Ventura) or later, Apple silicon or Intel | [reckless-ir-capture-macos.pkg](https://github.com/reckless-technology/ir-capture-releases/releases/latest/download/reckless-ir-capture-macos.pkg) | signed and notarized installer |
| Windows 10 or 11, 64-bit | [reckless-ir-capture-win64-setup.exe](https://github.com/reckless-technology/ir-capture-releases/releases/latest/download/reckless-ir-capture-win64-setup.exe) | signed installer |
| Linux x64: Ubuntu 24.04 or later, and Debian-family systems with glibc 2.38 or later (Debian 13, Mint 22) | [reckless-ir-capture-linux-amd64.deb](https://github.com/reckless-technology/ir-capture-releases/releases/latest/download/reckless-ir-capture-linux-amd64.deb) | `sudo apt install ./reckless-ir-capture-linux-amd64.deb` |
| Linux x64, any distribution with glibc 2.38 or later | [reckless-ir-capture-linux-x64.tar.xz](https://github.com/reckless-technology/ir-capture-releases/releases/latest/download/reckless-ir-capture-linux-x64.tar.xz) | the app and the tool to run from anywhere |

Every release is listed under [Releases](https://github.com/reckless-technology/ir-capture-releases/releases) with
its notes and `SHA256SUMS`, each file's checksum. The download page is at
[recklesstechnology.com](https://recklesstechnology.com/plugins/download/#ir-capture), and what the app does and how to
use it at [recklesstechnology.com/ir-capture](https://recklesstechnology.com/ir-capture/).

This repository holds the downloads alone. Reckless IR Capture is free to use under the end-user licence the macOS and
Windows installers show and every download carries (also at
[recklesstechnology.com/legal/ir-capture-eula](https://recklesstechnology.com/legal/ir-capture-eula/)); it is not open
