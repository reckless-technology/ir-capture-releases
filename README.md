# Reckless IR Capture

The downloads of Reckless IR Capture: it measures the impulse response of whatever sits between an output and an
input of an audio interface - a power amplifier into a speaker cabinet with a microphone in front of it, a pedal, a
room - and exports it as a WAV file for a cabinet simulator or a convolution reverb. Free for any use, for macOS,
Windows and Linux, with a command-line tool beside the app.

| | | |
|---|---|---|
| macOS 13.3 (Ventura) or later, Apple silicon or Intel | [reckless-ir-capture-macos.pkg](https://github.com/reckless-technology/ir-capture-releases/releases/latest/download/reckless-ir-capture-macos.pkg) | signed and notarized installer |
| Windows 10 or 11, 64-bit | [reckless-ir-capture-win64-setup.exe](https://github.com/reckless-technology/ir-capture-releases/releases/latest/download/reckless-ir-capture-win64-setup.exe) | signed installer |
| Linux x64: Debian, Ubuntu, Mint | [reckless-ir-capture-linux-amd64.deb](https://github.com/reckless-technology/ir-capture-releases/releases/latest/download/reckless-ir-capture-linux-amd64.deb) | `sudo apt install ./reckless-ir-capture-linux-amd64.deb` |
| Linux x64, any distribution with glibc 2.38 | [reckless-ir-capture-linux-x64.tar.xz](https://github.com/reckless-technology/ir-capture-releases/releases/latest/download/reckless-ir-capture-linux-x64.tar.xz) | the app and the tool to run from anywhere |

Every release is listed under [Releases](https://github.com/reckless-technology/ir-capture-releases/releases) with its notes and `SHA256SUMS`, each file's checksum. The download
page is at [recklesstechnology.com](https://recklesstechnology.com/plugins/ir-capture/).

This repository holds the downloads alone. Reckless IR Capture is free to use under the end-user licence each
installer shows (also at [recklesstechnology.com/legal/ir-capture-eula](https://recklesstechnology.com/legal/ir-capture-eula/));
it is not open source. Questions, bugs and ideas: hello@recklesstechnology.com.
